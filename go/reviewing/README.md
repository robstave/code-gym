# Go code review practice

Each case contains a runnable Go program with an intentional defect. Start with
the case's README to understand the intended behavior, then review `main.go`.
Try to explain what goes wrong, give an input that demonstrates it, and suggest
a fix before opening `ANSWER.md`.

From this directory, run an exercise with Go:

```powershell
go run .\case1\main.go
```

Replace `case1` with the case you want to practice. The examples use only the Go
standard library and do not need a Go module. Some compile and run successfully
while producing an incorrect result; a successful run is not proof of
correctness.

You can ask an AI for a small hint, a stronger hint, or a full explanation.
Repository instructions ask the assistant not to reveal the answer unless you
request it. `ANSWER.md` files contain spoilers.
